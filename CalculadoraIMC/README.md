# 🧮 Calculadora IMC

Aplicação desktop desenvolvida em **Java Swing** durante minha formação técnica em **Desenvolvimento de Sistemas pelo Senac**.

O projeto foi desenvolvido para praticar interfaces gráficas, eventos, entrada de dados, validações e navegação entre telas.

> 📚 Projeto acadêmico desenvolvido durante os estudos de Java. O código presente neste repositório corresponde à versão desenvolvida na atividade.

## 🎯 Objetivo

Criar uma aplicação gráfica para trabalhar com cálculo de IMC, gasto calórico e recomendações a partir dos dados informados pelo usuário.

## 🖥️ Funcionalidades

- Tela inicial
- Cálculo de IMC
- Interpretação do resultado
- Cálculo de gasto calórico
- Seleção de nível de atividade
- Recomendações com base nas calorias informadas
- Navegação entre telas
- Validação de entrada
