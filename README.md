# Java — Projetos Acadêmicos

Repositório que reúne projetos e atividades práticas desenvolvidos durante minha formação técnica em Desenvolvimento de Sistemas.

Os exercícios e aplicações registram minha prática com fundamentos de Java, lógica de programação, Programação Orientada a Objetos, interfaces gráficas, validação de dados, regras de negócio e integração com banco de dados relacional.

> Portfólio acadêmico em desenvolvimento. Os projetos representam atividades de estudo e não experiência profissional.

## Projetos

### [Cenaflix](Cenaflix_java_jdbc/README.md)

Aplicação desktop desenvolvida como atividade acadêmica do Senac para cadastrar, consultar, atualizar e excluir filmes, com interface Java Swing e persistência no MySQL por meio de JDBC. Inclui filtro por categoria e validação de entradas.

**Conceitos praticados:** Java, Swing, JDBC, MySQL, CRUD, consultas parametrizadas com PreparedStatement e separação entre modelo, conexão, DAO e interface.

[Ver código, imagens e instruções de execução](Cenaflix_java_jdbc/README.md).

### [SoftNutri](SoftNutri/README.md)

Aplicação desktop em Java Swing para cadastro e gerenciamento de consultas nutricionais.

**Conceitos praticados:** Java, POO, Swing, JFrame, JTable, modelos de tabela, validações e organização de telas.

### [Sistema de Funcionários](SistemaFuncionarios/README.md)

Projeto para praticar conceitos de orientação a objetos.

**Conceitos praticados:** herança, classe abstrata, polimorfismo, sobrescrita de métodos, arrays e entrada de dados.

### [Sistema Contábil](sistemaContabil/README.md)

Aplicação de cadastro e cálculo de diferentes impostos.

**Conceitos praticados:** interfaces, polimorfismo, listas, ArrayList e regras de cálculo.

### [Calculadora IMC](CalculadoraIMC/README.md)

Aplicação desktop para calcular o índice de massa corporal.

**Conceitos praticados:** Java Swing, JFrame, componentes de interface, eventos e validação de entradas.

### [Sistema de Agência de Viagens](sistema-agencia-viagens-java/README.md)

Aplicação de console desenvolvida em Java para simular operações de uma agência de viagens, incluindo transporte, hospedagem, pacotes e vendas.

**Conceitos praticados:** classes e objetos, encapsulamento, associação entre classes, objetos que utilizam outros objetos e implementação de regras de negócio.


## Tecnologias e ferramentas

- Java
- Programação Orientada a Objetos
- Classes, objetos e encapsulamento
- Herança, polimorfismo e interfaces
- Arrays, List e ArrayList
- Java Swing
- JDBC e MySQL
- CRUD e consultas parametrizadas com PreparedStatement
- JFrame, JTable e JOptionPane
- Scanner
- NetBeans

## Objetivo

Consolidar os fundamentos de Java por meio de exercícios e projetos, compreendendo a responsabilidade de cada classe, o fluxo da aplicação e a implementação das regras de negócio.

## Evolução

Novas atividades serão adicionadas conforme o avanço da formação. A documentação de cada projeto deve ser consultada para verificar funcionalidades, requisitos e estágio de desenvolvimento.
