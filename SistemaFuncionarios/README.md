# 👥 Sistema Funcionarios

Projeto acadêmico desenvolvido em **Java** durante minha formação técnica em **Desenvolvimento de Sistemas pelo Senac**.

O objetivo principal foi praticar conceitos de **Programação Orientada a Objetos**, especialmente herança, classe abstrata e polimorfismo.

> 📚 Projeto acadêmico desenvolvido durante os estudos de Java. O código presente neste repositório corresponde à versão desenvolvida na atividade.

## 🎯 Objetivo

Criar um sistema simples para trabalhar com diferentes tipos de funcionários e calcular seus pagamentos utilizando herança e polimorfismo.

## 🖥️ Funcionalidades

- Cadastro de funcionários
- Funcionários assalariados
- Funcionários horistas
- Cálculo de pagamento
- Aplicação de aumento
- Exibição dos pagamentos

- Sobrescrita de métodos
