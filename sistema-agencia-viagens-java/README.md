# ✈️ Sistema de Agência de Viagens — Java

Projeto acadêmico desenvolvido em Java para praticar os fundamentos da **Programação Orientada a Objetos (POO)** por meio da simulação das operações de uma agência de viagens.

A aplicação organiza informações sobre transporte, hospedagem, pacotes de viagem e vendas, aplicando conceitos de modelagem de classes e regras de negócio.

## 🎯 Objetivo

Consolidar os fundamentos de Java e POO, compreendendo como estruturar classes, relacionar objetos e implementar cálculos e operações em uma aplicação de console.

## ⚙️ Funcionalidades

- Cadastro de cliente e forma de pagamento.
- Associação de transporte e hospedagem a um pacote de viagem.
- Cálculo do valor dos pacotes e de taxas adicionais.
- Cálculo da margem da agência.
- Conversão de valores de dólar para real.
- Geração de recibo no console.

## 🧠 Conceitos praticados

- Classes, objetos, atributos e métodos.
- Encapsulamento.
- Construtores e métodos de acesso.
- Associação e composição entre classes.
- Organização e implementação de regras de negócio.
- Entrada de dados utilizando `Scanner`.

## 🛠️ Tecnologias

- **Linguagem:** Java
- **Interface:** Console
- **Entrada de dados:** `Scanner`
- **Paradigma:** Programação Orientada a Objetos

## ▶️ Como executar

1. Clone ou baixe o repositório.
2. Abra o projeto em uma IDE compatível com Java.
3. Localize a classe que contém o método `main`.
4. Execute a aplicação.
5. Siga as instruções exibidas no console.
